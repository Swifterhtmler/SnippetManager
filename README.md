





# SnippetMagnet

SnippetMagnet is safari extension for managing code snippets right in your browsers tab bar. 




## Features

- Minimalistic design  
- Code snippet previews
- Data saved locally



## Installation

You can install the app from [app store](https://apps.apple.com/fi/app/snippetmagnet/id6768115181?l=fi&mt=12)
    
## FAQ

#### How to use the extension ?

- Add name for your snippet in the name field, click enter
- Paste the snippet and click enter
- To view your snippets click "View your snippets"
- Preview snippet by clicking the snippet field

#### How to enable the extension ?

Go to safari settings by pressing cmd + , to extension tab. Enable the extension by toggling it on.
